# GATGRILS v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic CPU experiment that recovers a predictive temporal grammar from local response coordinates of a trained recurrent model and verifies that the grammar is invariant under exact hidden-state gauge changes.

**Architecture:** A NumPy-only synthetic stream generator feeds a small tanh RNN trained by explicit backpropagation through time. A black-box recurrence wrapper creates exactly conjugate gauge twins; finite-difference Jacobians are reduced to similarity-invariant response features, clustered, and converted into an event-conditioned transition model. An experiment runner evaluates held-out invariant-feature forecasts, separate held-out JVP calibration, exact twin equivalence, baseline comparisons, and writes a complete JSON receipt.

**Tech Stack:** Python 3.11+, NumPy, pytest for development. No network, GPU, or external model download is required.

**Spec:** `docs/superpowers/specs/2026-09-23-gatgrils-design.md`

## Global Constraints

- Respect the approved v0 spec and its frozen pass thresholds exactly.
- Train and evaluate in float64; use deterministic per-seed NumPy generators.
- Do not expose hidden generator modes to model fitting, cluster selection, or grammar fitting.
- Use central differences and a discovery probe bank separate from the held-out probe bank.
- Gauge twins must use `F_G(h',u) = G F(G^-1 h',u)` and the corresponding transformed readout.
- Save per-seed receipts and aggregate metrics as JSON; retain negative and failed runs.
- Keep commands CPU-runnable with NumPy as the only runtime dependency.
- Write each behavior test before its implementation, observe the expected failure, then implement the smallest passing change.

## Review Focus

- **Mode leakage:** generator labels may appear in receipts but must not enter training, validation model selection, feature construction, or grammar fitting.
- **Near-singular gauges:** condition-number limits must be checked and rejected matrices must not silently enter the evaluation.
- **Finite-difference error:** step size and float64 precision must be fixed in configuration and checked against an analytic Jacobian only in a calibration test.
- **Complex eigenvalue ordering:** invariant feature construction must deterministically order conjugate pairs and remain finite near repeated eigenvalues.
- **Cluster label permutations:** gauge comparisons must use the specified label alignment before computing transition distance.


## Frozen pass rules copied from the spec

- Base and gauge-twin output maximum absolute discrepancy <= 1e-10 in float64.
- Median invariant-feature relative drift <= 1e-6 at gauge condition numbers 1 and 3; <= 1e-4 at condition number 10.
- After label alignment, gauge-twin transition-distribution total-variation distance <= 0.02.
- Grammar-conditioned held-out next-invariant-descriptor forecast NRMSE beats activation clustering and shuffled responses on at least 9/12 seeds, and has at least 10% lower median NRMSE than activation clustering.
- Ordered grammar held-out transition NLL beats both shuffled-order and bag-of-coordinates controls on at least 9/12 seeds.
- Held-out probe directions separately verify finite-difference Jacobian estimates; this calibration score is reported but is not used as the cross-gauge predictive score.
- Any failure of exact twin equivalence invalidates that run. Other unmet gates are reported as failures without tuning thresholds after results are observed.
