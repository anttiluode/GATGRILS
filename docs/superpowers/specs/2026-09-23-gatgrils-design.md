# GATGRILS v0 Design

**Date:** 2026-09-23

## Purpose

GATGRILS (Gauge-Aware Temporal Grammar Recovery in a Learned System) tests whether local response behavior in a trained recurrent model can be grouped into reusable computation coordinates whose temporal grammar predicts future responses, and whether that description survives a change of hidden-state basis that leaves the model's input/output behavior unchanged.

The claim is deliberately bounded to a synthetic recurrent model. This is a method test, not a claim about a universal algorithm, biological equivalence, or transformer interpretability.

## Design choices

Three routes were considered:

1. **Probe a transformer directly.** High relevance, but the number of layers, heads, and nuisance symmetries makes the first gauge test hard to interpret.
2. **Use a hand-specified operator machine.** Clean ground truth, but it does not test whether a learned system contains recoverable coordinates.
3. **Train a small recurrent model, then construct exact gauge twins.** This tests learned dynamics while keeping the gauge relation mathematically controlled. This is the v0 choice.

## Experimental object

Train a compact deterministic recurrent network to predict symbol streams generated by a process with a persistent latent transition mode. The latent mode changes at sparse boundaries. The network receives only the symbol sequence and next-symbol objective; its hidden-state labels and the generator's mode labels are unavailable to coordinate discovery. Training, validation, and test streams use disjoint seeds.

After training, freeze the network. Treat its recurrent update as a black box F(h, u), where h is its hidden state and u is the current input. At held-out states, estimate the local Jacobian J_t = dF(h_t,u_t)/dh using a fixed bank of central-difference probes. A separate probe bank is reserved to test local-response predictions.

## Gauge twins

For an invertible, well-conditioned matrix G, define an exactly conjugate system in coordinates h' = G h:

    F_G(h',u) = G F(G^-1 h',u)
    readout_G(h') = readout(G^-1 h')

This twin must produce the same outputs on the same input tapes to numerical precision. Its local Jacobian is J'_t = G J_t G^-1. Raw activation coordinates and flattened Jacobians may change; similarity invariants must not.

Use a preregistered panel of orthogonal and general invertible G matrices, with condition numbers 1, 3, and 10. Run all calculations in float64. Reject a gauge draw if its condition number exceeds the assigned bound.

## Response coordinates and temporal grammar

Build per-time response features from similarity invariants of J_t: normalized characteristic-polynomial/eigenvalue features and rank diagnostics. Include ordered short-window trace features, such as tr(J_t J_(t+1)) and tr(J_t J_(t+1) J_(t+2)), so the descriptor can retain relative operator order that per-step spectra alone discard. State clearly which feature subset is used in each reported result.

Cluster response features into candidate coordinates. Select the cluster count on validation data only, using one frozen description-length criterion. Construct a first-order event-conditioned transition model over the resulting coordinate sequence. Use a fixed label-alignment procedure only for comparisons between gauge twins; do not use hidden generator labels to fit or select the grammar.

## Controls

- **Activation clustering:** same clustering and model-selection procedure on raw h_t; measures what location-only coordinates recover.
- **Per-step invariant only:** omits ordered trace features; tests whether temporal invariants add information.
- **Shuffled response sequence:** preserves the feature distribution but destroys its order.
- **Bag of coordinates:** preserves coordinate counts but discards transition order.
- **Held-out probe bank:** tests whether local response predictions generalize beyond discovery directions.
- **Gauge twin:** exact same computation in another hidden basis.

Hidden mode labels may be used after all choices are frozen to report diagnostic mutual information and transition agreement. They are not the primary target: two hidden labels that induce indistinguishable future responses need not remain separate.

## Measurements and frozen v0 pass rule

Report per seed and aggregate across 12 deterministic seeds:

1. Same-tape output discrepancy between each base model and its gauge twins.
2. Relative drift of invariant response features and aligned grammar transition probabilities across each twin pair.
3. Held-out probe-response NRMSE for a grammar-conditioned response predictor, compared with activation, shuffled-response, and per-step-only controls.
4. Held-out coordinate-transition negative log likelihood compared with shuffled-order and bag-of-coordinates controls.
5. Post-hoc association with generator modes, clearly labeled diagnostic.

Pass requires all of the following:

- Base and gauge-twin output maximum absolute discrepancy <= 1e-10 in float64.
- Median invariant-feature relative drift <= 1e-6 for condition numbers 1 and 3, and <= 1e-4 for condition number 10.
- After label alignment, gauge-twin transition-distribution total-variation distance <= 0.02.
- The grammar-conditioned held-out probe NRMSE beats activation clustering and shuffled responses on at least 9 of 12 seeds, with at least 10% lower median NRMSE than activation clustering.
- Ordered grammar held-out transition NLL beats both shuffled-order and bag-of-coordinates controls on at least 9 of 12 seeds.

If the exact gauge-twin output check fails, the run is invalid. If invariance passes but predictive criteria fail, report a negative result: gauge-invariant response coordinates were recovered, but this grammar did not earn predictive value. No metric may be dropped after seeing results.

## Scope boundaries

V0 does not claim unique or minimal coordinates, causal sufficiency, robustness to arbitrary ill-conditioned bases, recovery of every hidden mode, or superiority to a recurrent network as a predictor. Local Jacobians describe the system only near the sampled states and under the tested traffic. The MDL-like criterion selects among the tested cluster counts; it does not prove a globally minimal grammar.

## Deferred tests

- Distinguish two genuinely different learned internal computations with matched input/output behavior.
- Test stability across independently trained networks, not only exact gauge twins.
- Test nonlinear probe amplitudes and whether coordinates change with traffic.
- Apply the recovered method to a small transformer residual stream, with its actual symmetry group declared in advance.

## Implementation boundary

Keep v0 CPU-runnable and deterministic. Prefer NumPy and the repository's eventual minimal test dependencies. Save raw receipts, configuration, and per-seed metrics as machine-readable JSON; the README must state both passing and failing gates.
